# LayarKita

Simulasi pemesanan tiket bioskop dengan React dan CSS lokal untuk kegiatan UI/UX kelas X RPL.

```sh
npm install
npm run dev
```

Buka `http://127.0.0.1:5173/`. Mode observasi: `http://127.0.0.1:5173/?mode=observasi`.

`npm test` memeriksa aturan pemesanan. `npm run build` menghasilkan folder `dist`; `npm run preview` menayangkan hasil build. Panduan pembelajaran ada di `CATATAN_GURU.md` dan tidak ditautkan dari website.
